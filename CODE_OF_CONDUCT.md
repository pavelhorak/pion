# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc], in full and
without modification. The canonical text is at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

It is adopted by reference rather than copied here deliberately: a pasted copy
drifts from the canonical version and nobody notices, and a subtly altered
code of conduct is worse than none.

## Scope

It applies in this repository — issues, pull requests, discussions, commit
messages and code review — and anywhere someone is representing the project.

## Reporting

Report to **pion@pavelhorak.com**.

Two things you should know before deciding whether to report:

**This project has one maintainer.** Reports come to the same person who writes
the code, which means there is no independent body to appeal to. That is a real
limitation and worth stating plainly rather than implying a process that does
not exist. If the problem is with the maintainer's own conduct, GitHub's
[reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github)
are the escalation path.

**Reports are handled privately.** You will get an acknowledgement; you will not
get a public thread about your report unless you ask for one.

## Enforcement

The Contributor Covenant's enforcement guidelines (correction, warning,
temporary ban, permanent ban) apply as written.

One project-specific note, because it comes up in technical projects: **being
right is not a defence for being unpleasant, and being wrong is not a
violation.** Disagreement about a benchmark, an architecture or a decision is
the normal business of this repository and is welcome in strong terms. Contempt
for the person on the other side of it is not.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
