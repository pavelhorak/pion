# cla-signatures

This branch stores the Contributor Licence Agreement signatures for Pion.

The CLA workflow (`.github/workflows/cla.yml` on `main`) writes them to
`signatures/version1/cla.json` when a contributor signs on a pull request.
The CLA itself is [CLA.md](https://github.com/pavelhorak/pion/blob/main/CLA.md).

Do not merge this branch into `main`, and do not protect it: the workflow
commits here.
